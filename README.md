
# House Price Prediction Using Linear Regression

# Project Overview

This project focuses on predicting house prices using Machine Learning techniques. It uses the California Housing dataset and applies Linear Regression to understand the relationship between housing features and median house values.

# Objective

To develop a Machine Learning model that predicts house prices based on various housing features using Linear Regression.

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

# Tasks Performed

- Loaded and explored the California Housing dataset.
- Performed data preprocessing and checked the dataset.
- Handled categorical features using one hot encoding.
- Applied feature scaling to prepare the data.
- Implemented a Linear Regression model.
- Trained the model using the prepared dataset.
- Evaluated model performance using regression evaluation metrics.

# Outcome

Successfully developed and trained a Linear Regression model using the California Housing dataset to predict median house values based on housing features.
